# Roadmap

## Version 0.1

- [x] Local-first commit suggestions with optional cloud providers
- [x] Explicit consent before sending staged diffs to cloud providers
- [x] Sensitive-filename checks and structured message validation
- [x] Offline repository checklist with JSON output and strict mode
- [x] Automated tests and Linux/Windows CI on Node.js 22 and 24
- [x] Usage guides and security documentation

## Planned improvements

- [ ] Live-provider integration tests for Ollama, OpenAI and Anthropic
- [ ] Interactive message editing and regeneration
- [ ] Configurable team commit conventions
- [ ] Additional language and CI-system checks for Repo Doctor
- [ ] Standalone distribution for each tool

Suggestions and reproducible bug reports are welcome. Planned features have no scheduled release dates.
